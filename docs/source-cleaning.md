# Source Cleaning Record

The package was assembled from the CTD configuration, format contract, input/object model, Word mapping notes, first-principles notes, customer feedback summaries, and audit reports under `格式skill试验/`. The runtime package keeps only generalized rules.

- Confirmed defaults became profile configuration or formatting rules.
- Unconfirmed, contradictory, chapter-specific, and client-local requests became `profiles/ctd/open-questions.md`.
- Historical failures became principle/rule/detection/counterexample entries in `profiles/ctd/failure-modes.md`.
- Real project inputs, outputs, names, and confidential DOCX files were not copied into the package.
- The base DOCX files here are development candidates generated from a clean document; desktop Word save/reopen purity evidence is still a release gate.
