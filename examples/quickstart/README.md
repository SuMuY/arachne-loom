# Quickstart Artifacts

These files are test and demonstration artifacts for the `arachne-loom` tool.

- `build/document.docx`: smallest stable table/reference handoff.
- `build-figure-no-lists/document.docx`: image, figure caption, and figure-reference probe.
- `build-lists-probe/document.docx`: body TOC, table list, and figure list probe.
- `sample.md` and `config.json`: minimal input used by the 60-second quickstart.
- `figure-sample.md` and `figure-config.json`: extended figure/list input.

The `negative-fixtures/` directory holds intentionally broken DOCX files used by inspector tests and failure-mode documentation. Do not use them as templates or starting documents; see `negative-fixtures/README.md`.
