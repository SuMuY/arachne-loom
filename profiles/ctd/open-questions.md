# Open Questions

These decisions are intentionally not defaults in the runtime profile:

- Final table-of-contents, table-list, and figure-list order and headings.
- Whether future clean submissions use final display text or accepted revisions.
- The supported scope and failure handoff for comment restoration.
- Chapter-specific caption numbering variations beyond the v0 CTD profile.
- Explicit client-local formatting exceptions.
- Whether literature citations should be enabled after a native, updateable implementation is accepted.
- Desktop Word version/platform evidence for the seven behavior tests.
